# GenieCodeSkills
A set of Skills for Genie Code based on real word customer workloads:
- **AlteryxToPythonSpark** — converts Alteryx workflows into Python / PySpark notebooks.
- **alteryxToLakeflowDesigner** — converts Alteryx workflows into Databricks Lakeflow Designer (Visual Data Prep ETL) pipelines, materialized to Unity Catalog Delta tables.
